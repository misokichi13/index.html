# 会議音声ハイライト要約ツール（旧版）

会議の音声ファイル（WAV / M4A / MP3）をGemini APIで文字起こし・要約するブラウザツールです。AIが自動補完した箇所は赤いハイライトで表示され、その場で手直しできます。

公開URL: https://misokichi13.github.io/index.html/

> 後継の文字起こしツール（長尺WAVを分割して処理する版）があるため、このリポジトリは旧版として残しています。

## 使い方
1. Gemini APIキーを入力（ブラウザ内に保存され、次回から入力を省略できます）
2. 音声ファイルを選ぶ
3. 「AI要約・文字起こしを実行」を押す

## 注意
- 20MBを超える音声は自動で圧縮されますが、圧縮は再生しながら行う方式のため、長い音声では圧縮にも同じくらいの時間がかかります
- 音声データはGemini API（Google）に送信されます
